**Vice Coast Studio** — an offline web app that turns any photo and a caption into GTA 6-style cover art: the multi-panel poster look with bold caption lettering and a Vice City sunset or neon colour grade, exported as a PNG to share. Six layouts (Quad Grid, Hero + Three, Full Bleed, Tilted Snaps, Nine Panel, Story Strip), five colour grades, crop / pan / zoom per panel, undo-redo, and export in 1080 × 1080, 1080 × 1350, 1920 × 1080 and 1080 × 1920. Everything runs offline in a desktop browser from static files — photos never leave the machine. All art, lettering and fonts are original (Archivo Black + Caveat under the SIL Open Font License).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080, add your photos, pick a layout and grade, write your caption, and export a PNG.
